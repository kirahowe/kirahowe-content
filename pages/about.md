# Hello! I'm Kira

I've been writing software since 2015, mostly doing full stack web development with a more recent focus on data processing and visualization tools. Clojure is my language of choice. I care about making software simple, reliable, and enjoyable to operate and maintain.

If I could afford to work on open source full time I would, but I currently work full time for Seeq.

You can see my active projects over on [GitHub](https://github.com/kirahowe).

I used to speak at conferences at give workshops before I had a kid. Some selected talks from my former life:
- [Clojure for Data Deep Dive (London Clojurians 2024)](https://www.youtube.com/watch?v=eUFf3-og_-Y)
- [Clojure for Data Science in the Real World (Conj 2023)](https://www.youtube.com/watch?v=MguatDl5u2Q)
- [Using Clojure for more than software development (re:Clojure 2022)](https://www.youtube.com/watch?v=BxVtQM6FPHU)
- [Visualizing Data with Hanami (re:Clojure 2021)](https://www.youtube.com/watch?v=C3kwcAJWJmE)

Now I build apps I always wished existed, with the help of AI to make more efficient use of my vanishingly scarce free time. Some of my favourites right now:
 - [claimgraph](https://github.com/kirahowe/claimgraph) -- an attempt to build an agent memory system that actually works
 - [compositor](https://github.com/kirahowe/compositor/) -- an attempt at a developer experience tool that works with the way I develop UIs now in this age of AI
 - [hosted-clay](https://github.com/kirahowe/hosted-clay/) -- an experimental platform that gives users a hosted clay notebook to play with, hoping it will inspire more people to check out Clojure's awesome data science stack
 - [this very website!](https://github.com/kirahowe/website) -- the link blog I always wanted but never had time to build
 - [clef](https://github.com/kirahowe/clef) -- all of my strongest opinions about how to build a good web app in Clojure, codified into a little helpful CLI
 - [finances](https://github.com/kirahowe/finances) -- a personal finance app that works the way I want
 - [reader](https://github.com/kirahowe/reader) -- an attempt to build a reading curation system that doesn't become just another overwhelming pile of unread articles

I thrive in environments that champion open-source innovation, value community engagement, and are dedicated to solving complex problems with elegant, sustainable solutions. There are lots of things I typically help companies with in my consulting work:

- Do you have a ginormous code base that nobody can make sense of? I can help you organize it.
- Do you have stakeholders coming at you from every direction asking for different things? I can help you communicate with them to make a plan to actually build something.
- Do you have piles of data you want to get answers from? I can help you find them.
- Do you have a disproportionate number of early-career developers on your team you need to level up quickly? I can teach them.
- Do you want to build a culture of open collaboration and engage the global open source developer community but aren't sure where to start? I can help you transform your development processes.

I'm not currently seeking new opportunities but always love to meet other people working on interesting problems.
